# Snake Mobile 🐍

Jeu mobile Snake en HTML5 avec support PWA (Progressive Web App).

## Fonctionnalités

- 🎮 Contrôles tactiles (boutons + swipe)
- ⌨️ Support clavier (flèches directionnelles)
- 📱 Installation sur l'écran d'accueil (PWA)
- 💾 Mise en cache offline (service worker)
- 🔄 Wrap-around aux bords de l'écran
- 💀 Game Over collision avec soi-même

## Comment jouer

1. **Mobile** : Utilisez les boutons directionnels ou faites glisser sur le canvas
2. **Desktop** : Utilisez les touches fléchées
3. **But** : Mangez les pommes (f0f) pour grandir sans vous mordre !

## Installation PWA

Sur mobile :
- Chrome Android : Menu ⋮ → "Ajouter à l'écran d'accueil"
- Safari iOS : Partager → "Sur l'écran d'accueil"

## Déploiement

Ouvrez simplement `index.html` dans un navigateur ou déployez sur un serveur web.
